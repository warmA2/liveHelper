# B站直播辅助助手

连接 B 站直播间，实时采集弹幕 / 进场 / 礼物 / 上舰 / 醒目留言等全部事件，落库沉淀，并在浏览器控制台里看实时弹幕流、观众列表、AI 画像与主播生涯统计。

## 功能

- **实时弹幕流**：进场、发言、礼物、上舰、SC 实时滚动；支持暂停 / 清屏，可切换到「礼物流水」只看付费记录
- **时间轴回看**：按天 / 按小时回看历史弹幕，随时「回到实时」
- **观众列表**：按活跃 / 最新 / 消费 / 进场 / 新增排序，支持昵称或 UID 搜索、只看本场、分页
- **用户画像面板**：概览 / AI 画像 / 行为 / 消费 / 发言 / 备注 六个分类
- **消费统计**：金瓜子流水、付费次数、粉丝牌折算消费，含每笔礼物明细
- **热门元素高亮**：弹幕里命中游戏 / 梗 / 番剧 / 音乐等词条时自动着色标注，词库可自行编辑
- **密度曲线**：全局或单个观众的弹幕 / 进场 / 礼物密度图（ECharts）
- **操作记录**：点一下记录「唱歌 / PK / 杂谈 / 看视频…」（默认时长可在 `data/actions.json` 里改），记录会以彩色色带落在密度曲线上，并在「查看记录」里给出各操作对弹幕 / 进场 / 礼物 / 流水 / 人气的影响对比表
- **身份标记**：手动给观众打标签（AI助手、房管、主播…），三处联动显示
- **主播生涯**：跨场次累计开播时长、天数、观众数、弹幕数、上舰数与流水
- **AI 画像**：可接入大模型生成观众画像，未配置时自动降级为本地规则画像

## 环境要求

- Python **3.10 或更高版本**
- 依赖：`aiohttp`、`brotli`（启动脚本会自动安装）

## 快速开始

### Windows

双击 **`run.bat`** 即可。脚本会自动完成：创建 `.venv` → 安装依赖 → 启动服务 → 打开浏览器。

### macOS / Linux

```bash
chmod +x run.sh
./run.sh
```

### 手动启动（任意平台）

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate    macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

启动后控制台地址为 **http://127.0.0.1:8765/**（会自动打开浏览器）。

## 首次配置（重要）

程序首次运行会在根目录生成 `config.json`，默认值是空的。**房间号不填，弹幕采集不会启动**，只会看到一个空控制台并在终端提示：

```
[!] config.json 里的 room_id 还是 0，请在网页右上角「设置」里填入你的直播间房间号。
```

在网页右上角点 **设置**，填写以下内容后保存（会自动重连）：

| 配置项 | 是否必需 | 说明 |
| --- | --- | --- |
| 直播间房间号 | **必需** | 短号或真实房间号都可以 |
| 登录 Cookie | 可选 | 不填为匿名模式，弹幕昵称会被 B 站打码成 `某***`，部分数据缺失；填写后显示真实昵称 |
| API Base URL + API Key | 可选 | 不填时 AI 画像降级为本地规则画像 |
| 启用大模型画像分析 | 可选 | 勾选后才会调用大模型 |

## 环境变量（可选，进阶）

敏感项支持用环境变量注入，这样 `config.json` 里可以只留空值，不会随仓库提交：

| 环境变量 | 覆盖的配置项 |
| --- | --- |
| `BILI_COOKIE` | `cookie` |
| `LLM_API_KEY` | `llm.api_key` |

优先级：环境变量 > `config.json`。来自环境变量的密钥不会被写回文件。

```powershell
# Windows（PowerShell，写入用户环境变量后需重开终端）
setx BILI_COOKIE "你的 Cookie"
setx LLM_API_KEY "你的 API Key"
```

```bash
# macOS / Linux
export BILI_COOKIE="你的 Cookie"
export LLM_API_KEY="你的 API Key"
```

## 常见问题

**控制台没有数据？**
检查是否已填直播间房间号，以及该直播间当前是否在直播。

**弹幕昵称都是 `某***`？**
B 站匿名模式下的现象，在「设置」里填入登录 Cookie 即可显示真实昵称。Cookie 失效后程序会自动回落到匿名连接。

**页面样式是旧的？**
按 `F5` 刷新即可，静态资源已设置 `no-cache`。

**AI 画像没生成？**
确认已填写 API Key 并勾选了「启用大模型画像分析」；未配置时只能得到本地规则画像。

## 安全说明

- `config.json`、`data/live.db*`、`.venv/`、`__pycache__/` 均已在 `.gitignore` 中排除，**不会**被提交
- 请勿把包含 Cookie / API Key 的 `config.json` 直接分享或上传
- Cookie 等同于 B 站账号登录态，泄露后他人可登录你的账号，务必妥善保管
